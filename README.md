# 广州众安搬家有限公司官网

## 打开网站
双击 `启动本公司后台.command` 可在本机同时预览官网和后台；也可以直接打开 `dist/index.html`。

## 修改资料
编辑 `site.json` 的 `phone`、`address`、`domain`。域名填写完整 HTTPS 地址，不带结尾斜杠。运行 `python3 build.py` 重建网站。

已接入电话 18922145428。地址与域名为空；填写后重建将自动更新可见地址、结构化数据、canonical、Open Graph URL、robots.txt 和 sitemap.xml。不输出虚构地址和占位域名。

## 发布
本目录自带独立后台，在线编辑需要可运行 Python 的服务器。公开网站根目录设为 `dist/`，后台经 HTTPS 反向代理到本目录的 `管理后台.py`。具体见 `部署说明.md`。仅上传 `dist/` 也可发布静态版本，但不能在线编辑。

## 内容和 GEO
页面直接输出完整 HTML，正文不依赖 JavaScript；含公司实体、FAQ、面包屑、文章结构化数据、语义标题、站内链接及移动适配。域名配置后输出 sitemap。GEO 无法保证任何引擎收录、排名或 AI 引用。

公司服务承接范围、价格、营业时间和资质需运营方确认后添加，当前不编造相关数据。生成图片为场景示意，不作为团队实拍或客户案例。电话咨询为真实入口；需求清单仅浏览器本地生成和下载，不发送，不代表预约。

## 源码
- build.py：页面内容、HTML 和结构化数据生成
- site.css：三种视觉主题、移动适配
- site.js：菜单和本地需求清单
- site.json：公司资料
- assets：生成图片原稿、网页压缩版本
- dist：可以直接部署的网站

## 新闻与案例
本站后台位于 `管理后台.py`，只读取本站的 `content.json`、`assets/uploads/` 与 `.admin-auth.json`。发布后自动重建本站的 `dist/`。可独立部署，与其他公司无运行依赖。
